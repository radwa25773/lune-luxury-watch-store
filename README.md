# LUNÉ — Luxury Women's Watch Store

## About the Project
LUNÉ is a luxury women's watch store UI/UX design project focused on elegance, simplicity, and a premium shopping experience.

## Project Goals
- Create an elegant and consistent visual identity.
- Design a clear and intuitive shopping journey.
- Make browsing products and completing purchases easy.

## Screens
- Home
- Collection
- Product Details
- Checkout
- Cart Confirmation
- Order Success

## Tools
- Figma
- UI Design
- UX Design
- Interactive Prototyping

## Design Direction
The design uses a black and gold color palette to communicate luxury and timeless elegance.
